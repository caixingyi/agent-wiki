## 题目

> 设计一个能处理多领域客户咨询的智能客服系统，支持多轮对话、知识库检索、人工转接。

## 需求分析

### 功能需求
- 自然语言理解与多轮对话
- 多领域知识库检索（产品、售后、技术等）
- 自动分类和路由
- 人工坐席转接
- 对话历史管理

### 非功能需求
- 响应时间 < 3 秒
- 支持并发 1000+ 会话
- 99.9% 可用性

## 架构设计

```
用户消息
  ↓
[API Gateway / WebSocket]
  ↓
[Router Agent] ← 意图识别 + 分类
  ↓
┌─────────────────────────┐
│  Product Agent          │ ← 产品咨询
│  Support Agent          │ ← 售后服务
│  Technical Agent        │ ← 技术支持
│  Escalation Agent       │ ← 人工转接
└─────────────────────────┘
  ↓
[RAG 知识库] + [业务 API] + [CRM 系统]
  ↓
[Response 质量检查 Agent]
  ↓
用户回复
```

## 关键组件

### 1. Router Agent
- 使用 LLM 做意图分类
- 维护对话上下文状态机
- 支持动态路由规则

### 2. 领域 Agent
- 每个领域独立的 System Prompt
- 独立的 RAG 知识库
- 特定的工具集（查询订单、退款等）

### 3. 记忆系统
- **短期记忆**：当前对话上下文（存 Redis）
- **长期记忆**：用户历史画像（存数据库）
- **共享记忆**：跨 Agent 的会话摘要

### 4. 质量保障
- 输出安全过滤
- 置信度评估，低于阈值转人工
- A/B 测试框架

## 面试追问

- **如何处理 Agent 回答错误？** → 添加 Guardrails + 人工审核 + 反馈闭环
- **如何降低延迟？** → 流式输出 + 缓存热点问答 + 异步工具调用
- **如何评估效果？** → CSAT 评分 + 解决率 + 转人工率 + LLM-as-Judge
