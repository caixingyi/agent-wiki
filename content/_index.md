这是一本关于 **AI Agent 开发**的资源指南，汇集了学习资源、面试题库、项目实战与学习路线。

随着大语言模型（LLM）的快速发展，AI Agent 已经成为最热门的技术方向之一。然而，这个领域的知识分散在各种论文、博客、GitHub 仓库中，缺乏系统化的整理。本站希望成为 Agent 开发者的一站式参考。

## 本站包括以下内容

- **[学习资源](resources/)**：主流 Agent 框架对比、RAG 最佳实践、Tool Use 指南等技术教程与论文解读。
- **[面经](interview/)**：AI Agent 相关岗位面试真题、系统设计题与参考答案。
- **[项目实战](projects/)**：从零构建 RAG Agent 等实战教程，附完整代码与架构解析。
- **[他山之石](learning-paths/)**：来自社区的学习路线、踩坑经验与转型故事。
- **[贡献者](contributors/)**：自动展示参与内容建设和项目维护的贡献者。

## 这本指南适合谁

- 想入门 AI Agent 开发的工程师
- 正在准备 Agent 相关岗位面试的求职者
- 希望了解 Agent 技术全貌的产品经理和研究者
- 任何对 LLM Agent、RAG、Multi-Agent 感兴趣的人

## 如何使用

通过左侧导航栏浏览各个板块，或使用顶部搜索功能快速查找内容。

每篇文章底部都有「在 GitHub 上编辑此页」的链接，如果你发现任何问题或想补充内容，欢迎直接提交 PR。
